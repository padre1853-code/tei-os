Primii pași

WinLow XP este un sistem de operare liber, cu un desktop clasic: bara de activități jos, butonul Start în stânga, ceasul și pictogramele de sistem în dreapta. Toate setările se fac din Panou de control (Start → Panou de control sau Super+I).

Tasta Super este tasta cu sigla de pe tastatură, de obicei între Ctrl și Alt.

Meniul Start

Apăsați butonul Start sau tasta Super. Sus apar programele preferate, în dreapta categoriile, iar jos sunt căutarea și butoanele pentru blocare, deconectare, repornire și oprire.

Scrieți direct numele unui program pentru a-l căuta. Clic dreapta pe un program → Adaugă la preferate sau Adaugă pe desktop.

Fișiere și dosare

Deschideți Computer de pe desktop sau apăsați Super+E. Bara de adrese acceptă căi precum /home sau adrese de rețea precum smb://server/partajare.

Ștergerea mută fișierele în Coșul de gunoi; Shift+Delete șterge definitiv. Clic dreapta într-un dosar → Deschide terminal aici sau Caută în acest dosar.

Internet și rețea

Pictograma de rețea de lângă ceas arată conexiunile disponibile; alegeți o rețea Wi-Fi și introduceți parola. Setările avansate (IP fix, VPN, proxy) sunt în Panou de control → Rețea și internet → Conexiuni de rețea.

Calculatoarele și dosarele partajate Windows apar în Rețea pe desktop.

Instalarea programelor

Panou de control → Programe → Adăugare sau eliminare programe deschide catalogul cu mii de programe gratuite. Căutați programul, bifați-l și apăsați Aplică.

Navigatorul Firefox se poate instala din fereastra Bun venit (Start → Bun venit).

Programe pentru Windows

Multe programe pentru Windows (.exe, .msi) pornesc cu dublu clic, prin Wine. Nu toate programele funcționează; cele mai vechi și mai simple au cele mai mari șanse. Setările Wine sunt în Panou de control → Programe → Programe Windows (Wine).

Imprimante și scanere

Majoritatea imprimantelor USB și de rețea sunt detectate automat. Pentru a adăuga una manual: Panou de control → Hardware și sunet → Imprimante → Adaugă. Scanarea se face din Scaner.

Actualizări

Sistemul verifică singur actualizările și vă anunță printr-o fereastră. Le puteți căuta oricând din Panou de control → Programe → Actualizări software. Driverele video și Wi-Fi suplimentare sunt la Hardware și sunet → Drivere suplimentare.

Conturi utilizator

Panou de control → Conturi utilizator. Puteți crea conturi standard sau de administrator, schimba parole și activa autentificarea automată. Operațiile cer parola unui administrator.

Domeniu Active Directory

Panou de control → Sistem și securitate → Sistem → fila Nume computer → Alăturare la domeniu. Introduceți numele domeniului, un cont de administrator al domeniului și parola.

Computerul trebuie să folosească drept server DNS controlerul de domeniu. După alăturare, utilizatorii domeniului se autentifică din ecranul de login cu Alt utilizator.

Restaurare sistem

Restaurarea sistemului salvează instantanee ale fișierelor de sistem (nu ale documentelor). Configurați-o o dată din Panou de control → Sistem și securitate → Restaurare sistem; dacă o actualizare creează probleme, alegeți un instantaneu și apăsați Restaurează.
